Al-Attrash Online - Al-Ameen integration
Solunera

مرحبا،

هاد الربط بين الأمين والمتجر الأونلاين. الأمين هو اللي بيبعت الأصناف والأسعار لعنا، نحنا ما منتصل بقاعدة بيانات الأمين وما منكتب عليها شي، وما منحتاج كميات.

Endpoint
POST https://attrash-pullman.onrender.com/api/v1/alameen/items

Headers
Authorization: Bearer <branch key>
Content-Type: application/json

كل فرع إله key لحاله، رح ابعتلك key فرع بولمان برسالة منفصلة.
لتجرب الـ key بدون ما تبعت شي: GET على نفس الرابط مع نفس الـ header.

Body

{
  "branch_code": "01",
  "sync_type": "changes",
  "sent_at": "2026-10-21T18:00:00+03:00",
  "items": [
    {
      "item_code": "1001",
      "unit": "قطعة",
      "barcode": "6281031255017",
      "name": "شامبو بانتين حماية من التقصف 400 مل",
      "price": 15000,
      "currency": "SYP",
      "category": "عناية شخصية",
      "active": true,
      "updated_at": "2026-10-21T17:55:00+03:00"
    }
  ]
}

الحقول
branch_code: رمز الفرع عندكم بالأمين (إجباري). لازم يكون نفس الفرع تبع الـ key.
sync_type: changes أو full (إجباري).
sent_at: اختياري.
item_code: رمز الصنف (إجباري).
unit: الوحدة. إذا الصنف إله أكتر من وحدة (قطعة، علبة، كرتونة) كل وحدة بسطر لحالها بسعرها. الافتراضي قطعة.
barcode: اختياري بس مفيد كتير إذا موجود.
name: اسم الصنف (إجباري).
price: سعر المفرق للوحدة (إجباري). رقم أو نص، عادي.
currency: الافتراضي SYP.
category: القسم، اختياري.
active: false إذا الصنف موقوف. الافتراضي true.
updated_at: اختياري.

التوقيت
changes كل 10-15 دقيقة، فيها بس الأصناف اللي تغيرت.
full مرة باليوم بالليل، فيها كل أصناف الفرع. أي صنف ما بيجي بالـ full منعتبره انحذف ومنشيله من المتجر.
الحد 20000 صنف بالطلب و 60 طلب بالدقيقة للفرع. الـ full لازم يكون بطلب واحد.
إذا بعتت نفس البيانات مرتين ما بيصير شي، فإذا فشل طلب عيده عادي.

الرد
200: {"ok":true,"received":3,"inserted":1,"updated":2,"deactivated":0,"rejected":[]}
إذا في صنف غلط الباقي بينحفظ، والغلط بيرجع بـ rejected مع السبب.
401 الـ key غلط أو ناقص
403 branch_code ما بيطابق الـ key
413 الطلب كبير
422 شكل البيانات غلط، التفاصيل بـ details
429 كتير طلبات
500 مشكلة عنا، ما انحفظ شي، عيد الطلب

ملاحظة: السيرفر الحالي تجريبي وبينام إذا ما إجاه طلب لربع ساعة، فأول طلب بعدها ممكن ياخد لحد دقيقة. حط timeout حوالي 90 ثانية.

تجربة سريعة
curl -H "Authorization: Bearer <KEY>" https://attrash-pullman.onrender.com/api/v1/alameen/items

curl -X POST https://attrash-pullman.onrender.com/api/v1/alameen/items -H "Authorization: Bearer <KEY>" -H "Content-Type: application/json" -d "{\"branch_code\":\"01\",\"sync_type\":\"changes\",\"items\":[{\"item_code\":\"1001\",\"name\":\"test\",\"price\":1000}]}"

خطوات التجربة
أول شي GET لنتأكد من الـ key، بعدين changes بـ 10-20 صنف ومنقارنهن مع الأمين، بعدين full لفرع بولمان كامل، وبعدها منشغل الإرسال التلقائي.

بدي منك
رمز فرع بولمان بالأمين (حاطين 01 مؤقتاً).
الأسعار بالليرة الجديدة ولا القديمة؟
جهاز الفرع عليه نت ثابت؟
قائمة كل الفروع مع رموزها.
وإذا عندك صيغة تصدير جاهزة من الأمين ابعتلي ياها، منتأقلم معها.
