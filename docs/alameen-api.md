# ربط برنامج الأمين مع متجر الأطرش أونلاين

**من:** Solunera · **لـ:** مبرمج الأمين · **الإصدار:** 1.0

الفكرة ببساطة: برنامج الأمين بكل فرع **بيبعت** الأصناف والأسعار لعنوان عندنا. نحنا ما منقرأ ولا منكتب شي على قاعدة بيانات الأمين، وما بدنا كميات.

---

## 1. العنوان والمفتاح

| | |
|---|---|
| العنوان | `POST {BASE_URL}/api/v1/alameen/items` |
| فحص الاتصال | `GET {BASE_URL}/api/v1/alameen/items` (نفس المفتاح، بدون body) |
| المفتاح | لكل فرع مفتاح خاص، منبعتلك ياه لحال (مو بهالملف) |
| الهيدرات | `Authorization: Bearer <مفتاح الفرع>` و `Content-Type: application/json` |
| البروتوكول | HTTPS فقط |

`{BASE_URL}` منبعتلك ياه أول ما يصير السيرفر جاهز.

## 2. شكل البيانات

```json
{
  "branch_code": "01",
  "sync_type": "changes",
  "sent_at": "2026-10-21T18:00:00+03:00",
  "items": [
    {
      "item_code": "1001",
      "unit": "قطعة",
      "barcode": "6281031255017",
      "name": "شامبو بانتين حماية من التقصف 400 مل",
      "price": 15000,
      "currency": "SYP",
      "category": "عناية شخصية",
      "active": true,
      "updated_at": "2026-10-21T17:55:00+03:00"
    }
  ]
}
```

| الحقل | إجباري | الشرح |
|---|---|---|
| `branch_code` | نعم | رمز الفرع عندكم بالأمين. لازم يطابق الفرع تبع المفتاح |
| `sync_type` | نعم | `changes` = بس اللي تغيّر. `full` = كل أصناف الفرع |
| `sent_at` | لا | وقت الإرسال (ISO 8601 مع المنطقة الزمنية) |
| `items[].item_code` | نعم | رمز الصنف بالأمين. ما بيتغيّر |
| `items[].unit` | لا | الوحدة (قطعة / علبة / كرتونة...). كل وحدة **سطر لحالها بسعرها**. الافتراضي "قطعة" |
| `items[].barcode` | لا | الباركود إذا موجود (بيساعدنا كتير بربط الأصناف بين الفروع) |
| `items[].name` | نعم | اسم الصنف متل ما هو بالأمين |
| `items[].price` | نعم | سعر المفرق للوحدة. رقم (مسموح نص، فواصل، أو أرقام عربية) |
| `items[].currency` | لا | `SYP` افتراضياً. خبّرونا إذا الأسعار بالليرة القديمة أو الجديدة |
| `items[].category` | لا | القسم أو المجموعة بالأمين |
| `items[].active` | لا | `false` إذا الصنف موقوف. الافتراضي `true` |
| `items[].updated_at` | لا | آخر تعديل على الصنف بالأمين |

**ما منطلب ولا منستلم كميات.**

## 3. متى تبعتوا

- **`changes`**: كل 10 إلى 15 دقيقة، بس الأصناف اللي تغيّر سعرها أو اسمها أو حالتها.
- **`full`**: مرة باليوم (مثلاً الساعة 3 الصبح)، كل أصناف الفرع. أي صنف ما بيجي بالـ `full` منعتبره انحذف من الأمين ومنخفيه من المتجر.
- الحد الأعلى: 20,000 صنف بالطلب الواحد، و 60 طلب بالدقيقة لكل فرع. إذا الفرع أكبر، قسّموا الـ `changes` على أكتر من طلب. الـ `full` لازم يكون بطلب واحد.
- إعادة إرسال نفس البيانات ما بتخرّب شي (منحدّث على أساس الفرع + رمز الصنف + الوحدة). إذا فشل الطلب، عيدوه.

## 4. الردود

نجاح (`200`):
```json
{ "ok": true, "received": 3, "inserted": 1, "updated": 2, "deactivated": 0, "rejected": [] }
```
إذا في صنف فيه غلط، الباقي بينحفظ والصنف الغلط بيرجع مع السبب:
```json
{ "ok": true, "received": 2, "inserted": 1, "updated": 0, "deactivated": 0,
  "rejected": [ { "index": 1, "item_code": "1002", "error": "price: price must be a positive number" } ] }
```

| الكود | المعنى |
|---|---|
| `401` | المفتاح ناقص أو غلط |
| `403` | `branch_code` ما بيطابق المفتاح، أو الفرع موقوف |
| `413` | الطلب كبير كتير |
| `422` | شكل الطلب غلط (التفاصيل بـ `details`) |
| `429` | طلبات كتير، استنوا دقيقة |
| `500` | مشكلة عندنا، ما انحفظ شي، عيدوا الطلب |

## 5. أمثلة سريعة للتجربة

فحص المفتاح:
```bash
curl -H "Authorization: Bearer <KEY>" {BASE_URL}/api/v1/alameen/items
```
إرسال صنف واحد:
```bash
curl -X POST {BASE_URL}/api/v1/alameen/items \
  -H "Authorization: Bearer <KEY>" -H "Content-Type: application/json" \
  -d "{\"branch_code\":\"01\",\"sync_type\":\"changes\",\"items\":[{\"item_code\":\"1001\",\"name\":\"تجربة\",\"price\":1000}]}"
```

## 6. خطة التجربة الأولى

1. منبعتلكم العنوان ومفتاح فرع بولمان.
2. تجربة `GET` للتأكد من المفتاح.
3. `changes` بـ 10 إلى 20 صنف، والمحاسب عندنا بيقارن مع الأمين من صفحة المتابعة.
4. بعدها `full` لكل أصناف فرع بولمان.
5. تفعيل الإرسال التلقائي (كل 15 دقيقة + مرة بالليل).

## 7. اللي بدنا ياه منكم

1. **رمز فرع بولمان** بالأمين.
2. **الأسعار بالليرة الجديدة ولا القديمة؟**
3. هل جهاز الفرع عليه إنترنت ثابت؟ إذا لأ، منحتاج نحكي عن برنامج صغير بيبعت لما يرجع الإنترنت.
4. إذا عندكم شكل جاهز لتصدير الأصناف، ابعتولنا ياه ومنتأقلم معه.
